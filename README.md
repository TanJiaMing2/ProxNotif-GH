# ProxNotif

> Diploma Final Year Project — a mobile notification app built with React Native.

## Overview

**ProxNotif** is a mobile notification application that helps users discover nearby offers. The project combines location-based functionality, database features, and map navigation in a React Native mobile experience.

This repository contains the source code for my Diploma Final Year Project.

## Features

- View nearby offers
- Receive notifications related to nearby offers
- Navigate to offer locations using maps
- Create and browse offers
- Search for available offers
- Location-based functionality
- Database-backed application features

## Running the Project Locally

Install the project dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

You can then open the project with Expo Go, an Android emulator, an iOS simulator, or a development build.
